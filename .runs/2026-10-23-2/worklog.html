Carry into the next attempt

  1. Never answer a clarifying question without attaching what you want to see. At T+5.6, same round-trip: “Both sheets, scale per sheet. Keep drawn and scheduled as two separate fields per room, and show me every room where they disagree before you write the JSON.”
  2. Type one observation about the data before the first instruction. “Two-page vector PDF, real text layer on both sheets, don't rasterise.” The phrase text layer is the one to own for this archetype — and “OCR” was the wrong word for it.
  3. Ask for the artifact, not the narration. “walk me through it” got prose; asking for the overlay gets the thing that proves the answer.
  4. When two sources disagree, preserve the disagreement. Report both labelled, name which the bid uses. Reconciling with a rule you supplied destroys the only independent check you had.
